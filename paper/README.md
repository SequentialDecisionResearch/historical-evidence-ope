# Paper and Public Article

`public_facing_article.pdf` is the current public explanation of the project.

The formal working paper is intentionally not included in this first upload package because its final author metadata and preprint identifier should be fixed before it becomes the canonical public paper.

After the arXiv or SSRN record is created:

1. add the final working-paper PDF to this folder;
2. add the preprint link to the root `README.md`;
3. update `CITATION.cff` so the working paper becomes the preferred citation.
